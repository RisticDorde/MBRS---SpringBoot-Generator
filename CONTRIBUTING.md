# Contribution Guide

Welcome to the MBRS Generator project!

## Branching Strategy
- `master` / `main` - Stable, integrated code.
- Feature branches - Create a branch for each issue you work on. E.g., `feature/M2-profile-setup` or `issue-5`.

## Commit Format
- Prefix commits with the issue number or topic (e.g., `[#5] Add initial UML profile` or `feat(profile): define entity stereotypes`).

## PR Review Flow
- Create a Pull Request against `master`.
- At least one teammate should review and approve the PR before merging.
- Ensure the project builds successfully (no generator errors) before merging.
